# 🔐 Quantum Cryptography – BB84 Protocol

Simulation of the BB84 Quantum Key Distribution (QKD) protocol.

## Features
- Full BB84 protocol simulation
- Eavesdropper (Eve) detection via QBER
- Cascade error correction
- Privacy amplification
- Post-quantum cryptography comparisons

## Protocol Steps
1. Alice prepares random qubits in random bases
2. Bob measures in random bases
3. Sifting – keep only matching-basis bits
4. Error estimation – detect Eve's presence
5. Error correction + privacy amplification
